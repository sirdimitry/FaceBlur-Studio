# Брендированный установщик Windows

Мастер установки основан на Inno Setup 6.7.3. Для этого бесплатного проекта
платные плагины и сервисы не нужны. Лицензия и условия использования:
https://jrsoftware.org/files/is/license.txt

## Готовый файл

`dist/installer/FaceBlur-Studio-1.1.23-Windows-Setup.exe`

Поддерживаются Windows 10/11 x64. Установка выполняется для текущего
пользователя в `%LOCALAPPDATA%\Programs\FaceBlur Studio`, без обязательных прав
администратора. Можно выбрать другую папку. Python, модель распознавания,
FFmpeg и библиотеки входят в установщик; загрузка дополнительных компонентов
при установке не нужна.

Мастер предлагает русский и английский языки, создаёт ярлык в меню «Пуск» и
по желанию на рабочем столе. В конце можно запустить приложение. Повторная
установка использует прежнюю папку. Удаление доступно через настройки Windows.
Пользовательские проекты и настройки в `%LOCALAPPDATA%\FaceBlurStudio`
не удаляются.

## Оформление

- Исходная иконка приложения: установщик, заголовок окна, ярлыки и список
  установленных приложений.
- Тёмное оформление Windows 11 с синими и фиолетовыми акцентами.
- Вертикальный баннер на приветствии и завершении.
- Широкий баннер под индикатором установки.
- Фирменная иконка в шапке остальных страниц и спокойный фон всех шагов.
- Ссылка `@sirdimitry` внизу мастера открывает https://x.com/sirdimitry.

Графика находится в `assets/installer/`. Исходные баннеры созданы встроенным
imagegen; точные промпты сохранены в `assets/installer/PROMPTS.md`.
`scripts/prepare_installer_assets.py` подготавливает размеры, сохраняя весь текст
баннеров, и добавляет оригинальную иконку и фон.

## Пересборка

Установите Inno Setup 6.7.3 или новее из https://jrsoftware.org/isdl.php.
Готовую папку приложения собирает `FaceBlur.Windows.spec`.

```powershell
.\.venv\Scripts\python.exe scripts/build_windows_installer.py --rebuild-app
```

Если приложение уже собрано, опустите `--rebuild-app`. Для нестандартного
расположения компилятора используйте `--compiler "C:\path\ISCC.exe"`.
Версия берётся из `main.py`; рядом с установщиком создаётся файл SHA-256.

## Проверка

```powershell
.\.venv\Scripts\python.exe scripts/verify_windows_installer.py dist/installer/FaceBlur-Studio-1.1.23-Windows-Setup.exe
```

Проверка отказывается заменять уже установленный экземпляр. Она устанавливает
программу в отдельную папку с кириллицей и пробелами, сравнивает все файлы с
исходной сборкой, проверяет повторную установку и запускает установленный
детектор на тестовом видео. Затем удаляет тестовую установку и проверяет
ярлыки, запись удаления и сохранность пользовательских данных. Логи и отчёт
остаются в `build/verification/installer-roundtrip`.

Проверка на этом компьютере не заменяет проверку на чистой Windows/VM.
Установщик не подписан коммерческим сертификатом. Публикация в GitHub Releases
в этот процесс не входит.

Проверено 1 октября 2026 года на текущей Windows 11: установка всех 1086 файлов
с проверкой SHA-256, повторная установка с сохранением проекта, запуск
установленного приложения с обработкой 12 кадров через ONNX Runtime DirectML,
удаление программы, ярлыка и записи удаления с сохранением пользовательских
проектов и настроек. Отчёт: `build/verification/installer-roundtrip-final/report.json`.
