# 🎭 FaceBlur Studio v1.1.23

**FaceBlur Studio** (AutoFaceBlur) — мощное десктопное приложение для локального, полностью автоматизированного размытия лиц на видео с использованием нейросетей. Инструмент сочетает в себе приватность (обработка идет только на вашем ПК), высокую скорость и интуитивно понятный интерфейс.

---

## 🚀 Ключевые возможности

* **Локальная обработка:** Ваши данные не покидают компьютер — полная конфиденциальность.
* **Автоматический трекинг:** Детекция объектов на базе модели **YOLOv8-face**.
* **Рендеринг на лету:** Мгновенный предпросмотр результата без предварительного рендеринга видео.
* **Гибкая настройка:** Полный контроль над формой масок, радиусом размытия, сглаживанием границ и отступами.
* **Интерактивное управление:** Включение/отключение лиц в один клик.
* **Управление проектами:** Сохранение и загрузка прогресса работы (`.fbp`).
* **Сохранение аудио:** Оригинальная звуковая дорожка сохраняется без изменений через FFmpeg.
* **Кроссплатформенность:** Гарантированно работает на **macOS**; поддержка **Windows** реализована в кодовой базе, но находится на стадии тестирования.

## 📦 Установка и запуск

### 0. Предварительные требования
Для запуска из исходного кода нужен установленный **FFmpeg**. В macOS-приложение FFmpeg включён и отдельная установка не требуется.

* **macOS**: `brew install ffmpeg`
* **Windows**: Скачайте с [ffmpeg.org](https://ffmpeg.org/download.html) и добавьте путь к `bin` в системную переменную `PATH`.

### 1. Клонирование репозитория
git clone https://github.com/sirdimitry/AutoFaceBlur.git
cd AutoFaceBlur

### 2. Настройка окружения и запуск

**macOS / Linux:**
python3 -m venv venv && source venv/bin/activate && pip install -r requirements.txt && python main.py

**Windows (PowerShell):**
python -m venv venv; .\venv\Scripts\Activate.ps1; pip install -r requirements.txt; python main.py

## DMG для Apple Silicon

Сборка включает Python, библиотеки, модель распознавания лиц и arm64 FFmpeg. Для повторной сборки на Mac с Apple Silicon: `venv/bin/pyinstaller --clean --noconfirm FaceBlur.spec`, затем `scripts/build_macos_dmg.sh`. В образе есть приложение и ярлык папки Applications.

Текущая тестовая сборка подписана локальной подписью. Для распространения с обычным первым запуском на другом Mac требуется сертификат Apple Developer ID и нотариализация DMG. Без них Gatekeeper может отклонить приложение, даже если все зависимости включены.

## 🐞 Журналы и диагностика

- Запуск из VS Code или терминала: `debug_app.log` в каталоге проекта.
- Установленное приложение macOS: `~/Library/Logs/FaceBlurStudio/debug_app.log`.
- Журнал автоматически ротируется при 5 МБ; сохраняются три предыдущих файла.
- Журнал может содержать локальные пути к видео и текст ошибок. Перед передачей третьим лицам проверьте его содержимое.

## Безопасность и ограничения

Видео обрабатывается локально. Внешние программы `ffmpeg` и `ffprobe` запускаются списком аргументов без shell. Модель `yolov8s-face.pt` загружается через PyTorch; заменять файл модели на полученный из непроверенного источника опасно. Автоматическое распознавание может пропустить лицо, поэтому перед публикацией просмотрите всё экспортированное видео. Приложение загружает кадры в память; для больших видео выберите короткий фрагмент.
